# OAS v0.19.3

Documentation refresh after the official package and workspace rollout.

- Rewrites the README around OAS's central value: durable, provider-agnostic
  specialist agents with exact OAS-managed curricula, compounding expertise,
  mixed-provider teamwork, package/config sovereignty, and Desktop situational
  awareness.
- Documents the now-published official package repositories, `oas-package/`
  payload convention, `oas.dev` non-Git workspace setup, and guided migration
  from 0.18 capability locks.

No runtime contract changes from v0.19.2.
